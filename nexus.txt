Replaces in-game fonts with OpenDyslexic and adds in contrast for easier to read text.

For compatibility with CJK make sure you first have this mod: 
[url=https://www.nexusmods.com/warhammer40kdarktide/mods/1113]Show CJK Glyphs Plus[/url]

[b]Requires:[/b] [url=https://www.nexusmods.com/warhammer40kdarktide/mods/1008]Simple Assets[/url]

[b]Mod Settings / Commands:[/b]
[spoiler]
[b]Font Settings[/b]
- Font Version [Default (Game Font), OpenDyslexic Version 3, OpenDyslexic Version 2, OpenDyslexic Regular]
- Use Font on HUD
- HUD Specific Scale (Multiplier)
- Small / Medium / Large / Huge Text Scale
- Disable Font in Chat Input
- Full Scale for CJK Glyphs

[b]High Contrast[/b]
- Enable Text Background Boxes
- Box Opacity (0 - 255)
- Horizontal & Vertical Padding
- Enable on General HUD
- Always on (Chat Messages, Killfeed, World Markers, Pings & Smart Tags, Nameplates, Interaction Prompts, Compass & Objectives)
[/spoiler]
